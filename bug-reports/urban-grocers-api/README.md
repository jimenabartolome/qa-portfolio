## Urban Grocers - Bug Reports

This section contains bug reports documented during testing of the Urban Grocers platform.

## Report Structure

Each bug report includes:

- Bug description
- Eviroment
- Steps to reproduce
- Expected result
- Actual result
- Severity
- Priority
- Supporting evidence
