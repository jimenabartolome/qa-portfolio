# Urban Routes – Car Sharing Testing

## Project Overview

This project focused on testing the car-sharing booking functionality of Urban Routes.

The testing activities included:

- UI and design validation
- Functional testing
- Test checklist creation
- Test case design and execution
- Positive and negative testing
- Bug reporting and documentation

## Testing Scope

- Booking form design
- Payment method functionality
- Add card functionality
- Booking button behavior
- Car reservation process

## Tools

- Jira
- Chrome DevTools
- Manual Testing

## Results

Multiple defects were identified, documented, and reported during the testing process.
